# 平台架构

frontend/src/pages 按四模块组织页面；components 保存共享面板和三维视图；composables 保留导航及候选点控制；lib/ros 负责共享订阅、TF 和显示类型；lib/scene 保存平台模型、场景和轨迹；platform 管理视觉及演示状态。

FastAPI 仅暴露四模块及其共同需要的文件、ROS 配置/检测、运行参数与录制接口。C++ 保留地图生成、切片、全局重定位和导航点云预览四个 CLI。

旧首页、收藏分区、Python GUI、网络扫描、costmap 回放、其他导出器和 Android 产物已移除。ros_tool_suite C++ 命名空间是保留算法的名称。

页面不自动连接 ROS。显式接入或加载离线地图后隐藏演示场地，真实与演示遥测分别管理。断线保留最后有效狗姿态；返回演示清除连接和离线地图。

狗原模型为 Y-up，统一转换为 ROS Z-up；应用完整四元数保留 roll/pitch，按位移速度驱动动作。候选点水平拖动保持 Z。

玻璃使用半透明底色、背景模糊、边缘高光和阴影。抽屉挂载到根层，避免祖先透明度切断背景采样。普通动画使用 CSS/Vue Transition；三维动画使用 Three.js，不额外增加动画运行时。
