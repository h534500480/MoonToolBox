# 图标资源目录

用于统一管理项目内各类图标资源，避免把安装包图标、源素材和临时导出文件散落到 `scripts/`、`frontend/` 或根目录。

## 目录结构

- `source/`
  - 放原始设计素材或高分辨率导出源文件。
  - 建议保留可再次编辑的来源文件，例如 `.svg`、大尺寸 `.png`。
- `runtime/`
  - 放当前项目真正参与打包和分发的成品图标。
  - Windows 安装包和桌面快捷方式默认读取这里的 `.ico` 文件。

## 当前约定

- 打包入口默认优先读取：
  - `assets/icons/runtime/moontoolbox.ico`
- 安装器本体图标可选读取：
  - `assets/icons/runtime/setup.ico`
- 若后续需要区分更多用途，可以继续在 `runtime/` 下按平台或用途细分，但应保持“源素材”和“打包成品”分离。

## 使用建议

- 设计修改后，先更新 `source/` 中的源素材。
- 确认导出版本可用后，再覆盖 `runtime/` 中用于打包的成品文件。
- 不要把随机下载的临时图标直接混放到根目录或 `scripts/` 中。
- `moontoolbox.ico` 主要给程序快捷方式和发行包使用，可以相对大一些。
- `setup.ico` 专门给 Inno Setup 生成的安装器 EXE 使用，建议控制体积，优先使用标准多尺寸 `.ico`，避免因为资源过大导致安装器编译失败。
